# LaTeX Article Paper Template

A minimal starter template for papers using the standard `article` document
class. Edit `main.tex` to add your title, author information, and paper content.

## Build

With a LaTeX distribution that includes `pdflatex`, compile the document twice:

```sh
pdflatex main.tex
pdflatex main.tex
```

The output is `main.pdf`. Replace the example text and bibliography entry before
using the template for a paper.
